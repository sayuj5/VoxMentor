# VoxMentor Roadmap

## Completed

- **Core Platform Skeleton**: Basic React + FastAPI integration.
- **Database Architecture**: PostgreSQL integration with SQLAlchemy and Alembic.
- **Authentication System**: Secure JWT login, registration, and Google OAuth 2.0.
- **Agora Voice Integration**: End-to-end integration with Agora Conversation AI for real-time low-latency voice practice.
- **AI Evaluation**: LLM-driven post-session scoring algorithm with Pydantic validation.
- **Reports & Dashboard**: Beautiful UI for session history and progressive tracking.
- **Landing Page**: Premium 3D-driven landing page and animated footer.
- **End-to-End Testing**: Comprehensive API tests for authentication, sessions, and evaluation flows.

## Current Focus

- **GitHub Release & Open Source**: Finalizing repository documentation, cleaning up Git history, securing credentials, and preparing for public visibility.
- **Deployment Preparation**: Preparing Dockerfiles and deployment manifests for cloud hosting.

## Future Exploration

- **Offline / Local LLM Fallback**: Exploring edge-based voice transcription and lightweight evaluation models.
- **Advanced Analytics**: Visualizing long-term progression in specific competencies (e.g., tracking "system design" vs "algorithms" separately).
- **Custom System Prompts**: Allowing users to upload their own resumes and job descriptions to tailor the AI agent's initial persona dynamically.
- **Multi-lingual Support**: Expanding the Conversation AI configuration to support non-English practice modes.
